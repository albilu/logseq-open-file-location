This release fixes attachment handling, plugin cleanup, and offline startup.

- Ctrl/Cmd-click now reveals embedded images, image overlays, audio, and video, including native player controls. Ordinary playback and image action buttons retain their behavior.
- Resolve graph asset paths, encoded filenames, fragments, `file://localhost` links, and Windows network-share roots correctly.
- Leave email, external URLs, and Markdown page links unchanged.
- Remove listeners and temporary media styling when the plugin is disabled or reloaded.
- Bundle a pinned local SDK so unpacked and packaged installs can initialize offline.
- Show missing-file errors and improve the containing-folder fallback.
- Test the shipped implementation directly and run checks before release packaging. Archives include the local SDK, license notices, and README demo.

Validation: 100 regression tests, 24 live packaged-plugin checks in Logseq 0.10.15 on Linux, trusted media-control clicks, lifecycle checks, native file-manager protocol handoff, and offline loading from an extracted ZIP. Native Windows/macOS file-manager behavior remains unverified.

To install, extract `logseq-open-file-location.zip` and select the extracted plugin folder in Logseq's **Load unpacked plugin** dialog.
